# dustar-code

个人学习与项目代码仓库。

## 目录结构

```
├── python/                 Python 学习代码
│   ├── basics/             基础语法（class、list、if-elif-else、loop、function、extra）
│   ├── numpy/              NumPy 学习（创建、索引切片、广播）
│   └── module/             自写模块
├── cpp/                    C++ 学习代码
│   └── 01-io/              输入输出
└── project/                项目
    ├── cellular-automata/  元胞自动机（1d / 2d）
    ├── cellular-complexity/ 元胞自动机与复杂性
    └── neural-network/     从零手写神经网络（含 MNIST）
```

## 说明

- `.ipynb` 为 Jupyter Notebook 文件
- `project/neural-network/mnist.npz` 为手写数字数据集
- 环境目录与教材不纳入版本控制（见 `.gitignore`）
